# hack-fa5087f9-turtle -- «Аким на 5 часов»

AI-симулятор управления городом. Команда получает виртуальный бюджет, принимает 5
решений по развитию 5 районов Астаны и получает итоговый Astana Quality of Life Score
с объяснением от AI.

Трек: Спец-трек Astana Innovations. Хакатон: HackAlem AI.

## Команда
- Томирис -- движок расчёта (`engine/`)
- [Имя 2] -- интерфейс (`frontend/`)
- [Имя 3] -- AI-объяснение + README/демо (`ai/`, документация)

## Структура
```
data/          -- исходные данные из ТЗ (районы, мероприятия, формула/правила)
engine/        -- расчёт Score: валидация решений, применение эффектов, формула
ai/            -- LLM объясняет уже посчитанный результат (не считает сам)
frontend/      -- интерфейс выбора решений (Streamlit)
```

## Правила игры (кратко)
- Бюджет: 100 у.е., ровно 5 решений, без повторов.
- Мероприятия типа "Район" требуют указания района, "Город" -- нет.
- Не более 2 мероприятий из одного направления (транспорт/экология/соцсфера/безопасность/сервисы).
- Есть несовместимые пары (`data/rules.json -> incompatible_pairs`) и синергии
  (`data/rules.json -> synergies`).
- Невалидный набор не считается -- возвращается причина.

Полная формула расчёта Score -- в `data/rules.json` и докстроке `engine/scoring.py`.
Проверочные значения (обязательно пройти тестами): базовый Score без решений = 52.56;
пример валидного набора -> Score ≈ 56.5.

## Запуск
```bash
pip install -r requirements.txt
pytest engine/test_scoring.py       # сначала убедитесь что движок считает правильно
streamlit run frontend/app.py       # затем поднимите интерфейс
```

## Пример проверки
1. Открыть интерфейс.
2. Выбрать набор: M7/Нура, M8/Нура, M10/Нура, M12 (город), M5/Сарыарка.
3. Убедиться, что стоимость = 95, Score ≈ 56.5, сработала синергия M10+M12.
4. Прочитать AI-объяснение результата.

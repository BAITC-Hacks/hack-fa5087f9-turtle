## Запуск актуальной версии

Остановить старый сервер через Ctrl+C, затем из корня проекта:

```bash
git pull --ff-only origin main
source .venv/bin/activate
unset OPENAI_API_KEY
python -m tools.demo --live-ai --port 8502
```

Открыть http://localhost:8502. `unset` убирает старое значение из терминала, чтобы использовать локальный `.env`. Вызов с `--live-ai` расходует API-токены; при переформулировке возможны два запроса.

# Проверка по материалам организаторов

Источники, предоставленные командой 23.09.2026:

- «Датасет районов.docx»: таблицы районов, 14 мер, синергии, формула и правила.
- «HackAlem AI_ «Аким на 5 часов» - AI-симулятор управления городом.docx»: must have и критерии оценки.

## Совпадение данных

Автоматически сопоставлены таблицы Word с `data/*.json`: совпали 50 исходных
значений показателей, пять долей населения, названия/направления/типы/цены/лаги/
эффекты всех 14 мер и десять весов. Правила бюджета, направлений, трёх синергий,
несовместимостей и формула также сверены с текстом датасета.

## Что проверяется

| Требование | Реализация и проверка |
|---|---|
| Одинаковые стартовые данные и бюджет | JSON-файлы; каждый расчёт загружает исходные данные |
| Ровно пять решений | `validate_decisions`; отдельный `run([])` нужен только для базового сравнения |
| Пять доступных направлений | Все присутствуют в каталоге; максимум две меры направления. По датасету не требуется по одной из каждого |
| Бюджет ≤100 | Валидатор и интерфейс; ровно 100 допустимо, 101 блокируется |
| Нет повторов и ошибочных районов | Тесты ID, районных и городских мер |
| Несовместимости | M1/M3 — глобально; M4/M7 и M5/M13 — только в одном районе |
| Лаг | Проверены ожидаемые дельты каждой из 14 мер |
| Три синергии | Бонус ровно +2 только в районе первой районной меры, без уменьшения лагом |
| Городские эффекты | Проверены во всех пяти районах; районные — только в выбранном |
| Неизменность данных | Проверены районы, каталог, правила и решения; результат — отдельная копия |
| Независимость от порядка | Все 120 перестановок контрольного набора дают одинаковый полный результат |
| Clip после суммы | Проверены верхняя и нижняя границы, положительные и отрицательные эффекты |
| Score | Среднее по населению, слабейший район, штраф за значения строго <40 |
| AI-анализ | Три качественных комментария + числовые факты движка; стоимость, сроки и синергии в контексте |
| Отказ API | Streamlit AppTest: нет ключа, таймаут и демонстрационный режим сохраняют Score и три таблицы |
| Настройки AI | Недоступный или повреждённый `.env` не ломает расчёт; три модели передаются API, смена модели убирает старое объяснение |
| Изменение сценария | Старый результат сбрасывается; новый валидный набор даёт другой Score |

## Границы проверки

**110 тестов прошли.** Автотесты используют подменённые ответы API и подтверждают интеграцию, обработку
ошибок и отображение. Они не подтверждают качество или доступность живой модели.
Прямые пробные запросы из изолированной среды проверки не смогли подключиться к OpenAI;
автоматизированное сравнение качества и времени всех доступных моделей не проводилось.
Пользовательский запуск 23.09.2026 подтвердил живые ответы GPT-4o mini и GPT-4.1 на контрольном сценарии, а также запуск Streamlit на порту 8502. В принятом ответе GPT-4.1 значения Score, крупнейших изменений, синергии, бюджета и лагов совпали с фактами движка. Редизайн Ардак включён в общую проверку интерфейса.
Проверка с реальным ключом выполняется кнопкой в приложении или
`python -m tools.check_ai --models gpt-4o-mini gpt-4.1-mini gpt-4.1`.

Проверенная среда: Python 3.14.7, Streamlit 1.64.0, OpenAI SDK 3.19.0, pytest 9.1.1.
Зависимости проверены командой `pip check`: конфликтов нет. Новая установка
через интернет в ограниченной среде не выполнялась. Запуск отдельного веб-сервера
был заблокирован ограничением на открытие локального порта (`PermissionError`);
интерфейс проверен через Streamlit AppTest, а не через браузер.
Точечная проверка состава ответа не гарантирует отсутствие любых смысловых
ошибок языковой модели. Данные синтетические; проект не прогноз реального города.

## Приоритеты проверки по ТЗ

Работоспособность — 25 баллов; техническая реализация — 25; README и
воспроизводимость — 25; ценность — 15; развитие и оригинальность — 10.
Обязательный сценарий и воспроизводимый запуск имеют приоритет перед новыми
опциональными функциями. Сравнение команд и случайные события не заявляются
реализованными. Проход в финал зависит от оценки жюри.
